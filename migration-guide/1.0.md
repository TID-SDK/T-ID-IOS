# T-ID Migration Guide 1.0

## Ломающие изменения

### Изменения, связанные со сборкой модуля:
1. Новое имя библиотеки: изменено с `TinkoffID` на `T-ID`, имя модуля при этом изменилось на `TID`. 
   
   В `Podfile` модуль теперь добавляется с помощью команды `pod T-ID`. Также в проекте следует использовать `import TID` вместо `import TinkoffID`. Для SPM все аналогично.
   Если вы используете конкретную версию библиотеки, то нужно ее изменить на `1.0.2`.

2. В структуре публичной части библиотеки все имена содержащие `Tinkoff` сокращены до `T`. 
   
   Необходимо переменовать имена используемых сущностей.

3. Изменен адрес для получения сертификатов SSL. 

   Необходимо отредактировать данные в `plist` по ключу `NSAppTransportSecurity` --> `NSExceptionDomains` --> заменить `tinkoff` на `t-bank-app` и `tbank`.  

4. Изменена зависимость от `TCSSSLPinning` на `TSSLPinningPublic`. 

   Если планируется использовать SSL пининг отдельно от `T-ID`, то модуль теперь добавляется с помощью команды `pod TSSLPinningPublic`, также необходимо изменить импорт `import TCSSSLPinning` на `import TCSSSLPinningPublic`. 

### Изменения, связанные с дизайном SDK:
Изменились цветовые стили, необходимо обновить данный параметр в соответвии с вашими потребностями:
- Было
    ```swift
    /// Цветовой стиль кнопки входа
    public enum TIDButtonColorStyle {
        /// Стандартная желтая тема
        case `default`
        /// Светлая тема
        case alternativeLight
        /// Темная тема
        case alternativeDark
    }
- Стало
    ```swift
    /// Цветовой стиль кнопки входа
    public enum TIDButtonColorStyle {
        /// Стандартная тема
        case primary
        /// Альтернативная светлая тема
        case alternativeLight
        /// Темная тема
        case dark
        /// Светлая тема
        case light
    }
## Неломающие изменения
### Изменения, связанные с дизайном SDK:
1. Новые логотипы
2. Новая логика отображения текста в кнопке. Теперь в кнопке отображается только тот текст, который был передан при создании кнопки. Если ничего передано не было или используется стандартная реализация, то будет отображаться `Т-Банк`

Все изменения, связанные с новым дизайном, можно "потрогать" на новом экране конфигурации кнопки T-ID.
